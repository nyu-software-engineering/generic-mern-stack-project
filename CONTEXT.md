# CareerHive

CareerHive helps students and recent graduates find jobs and manage their applications. This glossary names the product concepts represented by the wireframes.

## Language

**Application**:
A job opportunity the user has added to their personal tracker, together with its current stage, notes, and stage history.
_Avoid_: Job listing (the public opportunity), application form (the external company process).

**Tracker stage**:
One of Saved, Preparing, Applied, Interview, Offer, or Rejected used to organize the user's applications. Each application has one current stage.

**Stage preview**:
The collapsed portion of a nonempty tracker stage, showing up to two actual applications; one is shown when only one exists. A stage with no applications is omitted.
_Avoid_: Fixed two-item total, padded list.

**Expanded Saved state**:
The tracker variant showing all four Saved applications after the user expands its two-item preview. It represents the same tracker with a different expansion state.
_Avoid_: Extra tracker section, inconsistent default preview.
