# CampusMart
## About This Project
**CampusMart** is a **student-to-student** service marketplace where students can offer their skills and find help from other students.

Our goal is to **connect students** who need help with students who can provide it. For example, if a student needs tutoring for a specific course but cannot attend the official tutoring sessions due to scheduling conflicts, they can use **CampusMart** to find other students who offer tutoring for that course.

Through **CampusMart**, we hope to give students **more opportunities** to find the help they need while allowing service providers to improve their skills, gain experience, and potentially build their early careers.

## Product Vision and MVP
Our vision is to **create a convenient platform** where students can share their talents and help each other within the university community.

For our MVP, we plan to focus on the following features:

1. Student Accounts: Allow students to register, sign in, verify their university email, and manage their profiles.

2. Service Listings: Allow students to create, edit, and manage service listings with descriptions, prices, and availability.

3. Service Discovery: Allow students to browse services by category, search for specific services, and filter or sort results.

4. Booking System: Allow students to request services, manage bookings, and accept or decline requests as service providers.

5. Reviews and Ratings: Allow students to leave reviews, ratings, and comments about services.

## Project building and testing
To run the back-end, install Node.js and npm, then run:

```bash
cd back-end
npm install
npm run dev
```

The server will be available at http://localhost:3000. To run it without automatic restarts, use `npm start` instead of `npm run dev`.
