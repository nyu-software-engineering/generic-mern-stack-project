# Guide to Contributing
## Team Norms

For communication use the Mapmaker thread in teamtalk. Please respond to all messages within 24 hours unless group is notified beforehand of an absence

Daily Standup times and procedures to be determined. Team members are required to attend all standup meetings on Zoom unless notified beforehand of an abscence beforehand. 

One member( most likely Scrum Master)will post daily standup updates to course admins on the Mapmaker channel.

## Git Workflow:
[Mapmaker](https://github.com/agile-students-fall2026/generic-mern-stack-project-MapMaker)

 Install Git and clone the github repo above to local computer. Create a feature branch with a description of what task it is tied to. Work in the local repo and frequently push code to prevent merging issues. Use single line commit messages. Before approval to master branch, open a pull request to master. Have one other team member review the request and merge the pull request to master before deleting the feature branch( permissions yet to be enabled)


## Contribution Rules
Each task in a sprint backlog will have a member assigned to it. Each member is responsible for communicating what they have done and what they are working on during each daily standup. They will also be responsible for communicating any delays or spikes that are impeding them from accomplishing a task.
