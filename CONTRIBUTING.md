# Guide to Contributing

## Team Norms:

Each of our team members will do our best to contribute effectively to this project.

We will have 3 weekly teams meeting during the times of Tuesday 5pm, Thursday 8pm, and Saturday 12pm.
Meetings will be held on Google Meet and will last 15 - 45 minutes depending on the time needed.
During team meetings, we will discuss how to divide the work among team members during each sprint.

## Git Contributions:

Developers should always begin by pulling the latest changes in the repository before beginning to write code. Developers should work on current issues within the repository that still need to be solved. Each commit should include incremental changes, commit descriptions should be maximum one line.

When contributing, make to sure to follow our coding guidelines.
